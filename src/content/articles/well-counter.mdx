**ウェル型シンチレーションカウンタとは**、結晶の穴（井戸）に試験管を差し込み、中の血液や尿から出る放射線を数える装置です。

同じ「ウェル型」で試料を測る装置に、**ウェル型電離箱**もあります。<br />
ややこしいですよね。

診療放射線技師国家試験では、2 つの装置の違いを聞かれます。<br />
この記事では、2 つの装置の違いを表にまとめ、国試でひっかかりやすい点を解説します。

## 2つの装置の比較

| 比較項目           | ウェル型シンチレーションカウンタ           | ウェル型電離箱                                           |
| ------------------ | ------------------------------------------ | -------------------------------------------------------- |
| 主な役割           | 試料から出る放射線を**1個ずつ数える**      | 試料の**放射能の量**を測る                               |
| 測定原理           | 結晶が放射線で光り、その**光を数える**     | 気体の**電離でできる電流**を測る                         |
| 主に検出する放射線 | 主に **γ 線**（β 線の測定用ではない）      | 主に **γ 線**                                            |
| 向いている試料     | 放射能が**比較的低い**試料（血液・尿など） | 放射能が**比較的高い**試料（投与前のシリンジ・バイアル） |
| 放射能が高いとき   | 数えきれず、数え落としが増える             | 電流が大きく、**短い時間で**値が読める                   |
| 結果の単位         | **cps**（計数率）。効率で直すと **Bq**     | 校正にもとづく放射能（**Bq** など）                      |
| 液量の影響         | 液量で**計数効率が変わる**                 | 国試で問われるのはシンチ側                               |

<KeyPoint>
  シンチ＝光を数える・低い放射能・液量で効率が変わる ／
  電離箱＝電流を測る・高い放射能・高いほど短時間
</KeyPoint>

## 違いが生じる理由

**井戸型にする理由**
結晶に穴をあけ、試料を結晶で囲むためです。試料から四方に出る放射線を取りこぼしにくくなり、弱い試料でも数えやすくなります。

**液量で計数効率が変わる理由**
液量が増えると、試料が井戸の上のほう（入口側）まで広がります。入口に近い部分の放射線は穴の外へ逃げやすく、同じ放射能でも数えられる割合が変わります。そのため、液量や容器をそろえて測ります。

**ウェル型電離箱が高い放射能に向く理由**
シンチレーションカウンタは1個ずつ数えるので、多すぎると数えきれません。電離箱は1個ずつ数えず、電離でできた**電流の大きさ**を見ます。放射能が高いほど電流が大きく、短い時間で値が安定しやすくなります。

**Sv が出てこない理由**
Sv は、人の体が受けた放射線の影響を表す**線量**の単位です。試験管やバイアルの中の放射能（Bq）を表す単位ではありません。

## 国試でひっかかりやすい点

- ウェル型シンチレーションカウンタは、**β 線ではなく、主に γ 線**を数える。
- 表示単位は **Sv ではなく、cps や Bq**。Sv は人体の線量。
- ウェル型電離箱の測定上限は **1 GBq 程度ではない**。投与前の高い放射能を測る装置で、上限は機種と核種で異なる（99mTc で数百 GBq まで扱える機種もある）。
- ウェル型電離箱は、放射能が**高いほど長くかかるのではなく、短い時間で測れる**。

## まとめ

- **シンチレーションカウンタ**は、光を検出して**数える**。放射能の低い試料向きで、液量で計数効率が変わる。
- **電離箱**は、電離による**電流を測る**。放射能の高い試料向きで、高いほど短い時間で測れる。
- **cps** は計数率、**Bq** は放射能、**Sv** は人体の線量。試料の測定に Sv は使わない。
