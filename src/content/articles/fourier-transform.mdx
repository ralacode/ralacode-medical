**MRI のフーリエ変換再構成とは**、[k 空間](/medical/articles/k-space/)に並べた生データを**逆フーリエ変換**して MRI 画像を作る方式です。

受験生が混乱しやすいのはここです。**厳密な操作は逆フーリエ変換**なのに、試験問題や教科書では「**フーリエ変換再構成**」と呼ばれることが多い。本記事では、**何をしているのか**と**なぜフーリエ変換の枠組みなのか**を、用語の整理とセットで説明します。

## 厳密には「逆」フーリエ変換

MRI 画像の再構成で重要なのは、次の向きです。

<KeyPoint>
  k 空間（空間周波数） → 逆フーリエ変換 → 画像空間（位置ごとの信号）
</KeyPoint>

- **入力** … k 空間の複素生データ（[位相・周波数エンコード](/medical/articles/phase-frequency-encoding/)で埋めたもの）
- **出力** … 位置ごとの信号が並ぶ画像空間。私たちが見る MRI 画像はこちら

数学的に k 空間 → 画像へ進むのは **逆フーリエ変換（IFT）** です。「フーリエ変換をかけて k 空間に入れる」方向（画像 → k 空間）とは**逆**です。

## なぜ「フーリエ変換再構成」と呼ぶのか

国試では、方式全体をまとめて **フーリエ変換再構成** と表現することがあります（問文の「フーリエ変換再構成を用いる MRI 」など）。

| 言い方                 | 意味                                           |
| ---------------------- | ---------------------------------------------- |
| **逆フーリエ変換**     | 再構成で実際に行う数学操作（k 空間 → 画像）    |
| **フーリエ変換再構成** | フーリエ変換の枠組みで画像化する方式の**総称** |

試験文では「フーリエ変換」の語だけが出ても、文脈が**画像の再構成**なら **逆フーリエ変換の結果**を指していると読むことが多いです。「厳密な操作名」と「方式の総称」を使い分けて覚えると混乱が減ります。

## フーリエ変換は何をしているか

ここでは数式より**イメージ**で整理します。

MRI 画像は、位置ごとに信号強度が違う**2 次元の分布**です。フーリエ変換の考え方では、こうした分布を、いろいろな**粗さの模様（空間周波数成分）**の足し合わせとして表せます。

- **低い空間周波数** … 大まかな明暗（コントラスト）
- **高い空間周波数** … 細かい輪郭（分解能）

k 空間には、それぞれの成分がどれだけ含まれるかが並びます。**逆フーリエ変換**は、これらの成分を**合成し直して**、再び「位置ごとの信号」に戻す操作です。

## なぜ MRI はフーリエ変換の枠組みなのか

MRI の 2 次元画像化では、次の流れが一本につながります。

1. **勾配** … 位置の違いをラーモア周波数差・位相差として符号化する
2. **[位相・周波数エンコード](/medical/articles/phase-frequency-encoding/)** … 信号を空間周波数として k 空間にサンプルする
3. **逆フーリエ変換** … k 空間のデータから位置ごとの信号（画像）を再構成する

撮像の段階で信号はすでに**空間周波数**として整理されているため、画像化には「空間周波数 → 位置」への変換、すなわち**逆フーリエ変換**が自然に使われます。これが、MRI がフーリエ変換の枠組みで説明される理由です。

## k 空間との関係

|                    | k 空間                           | 画像空間                  |
| ------------------ | -------------------------------- | ------------------------- |
| **中身**           | 空間周波数ごとの信号（生データ） | 位置ごとの信号（画素値）  |
| **変換**           | 逆フーリエ変換の**入力**         | 逆フーリエ変換の**出力**  |
| **日常のイメージ** | 装置内部のデータ                 | 画面に表示される MRI 画像 |

k 空間の中心・周辺が担う情報（コントラスト／分解能）の詳細は [k 空間](/medical/articles/k-space/) の記事で解説しています。本記事では**変換そのもの**に焦点を当てます。

## 国試でひっかかりやすい点

- **再構成はフーリエ変換（順方向）で k 空間に入れる** … 誤り。生データはすでに k 空間にあり、**逆フーリエ変換で画像空間へ**出す。
- **再構成後の画素値は k 空間にある** … 誤り。画素値は**画像空間**にある。k 空間へ「戻して保管」するわけではない。
- **「フーリエ変換再構成」＝順フーリエ変換** … 方式名として使われているだけ、と読む。操作としては **逆フーリエ変換**。
- **振幅画像は虚部だけから求まる** … 誤り。複素データの実部・虚部の**両方**から信号強度（振幅）が求められる。

## まとめ

**MRI の画像化は、厳密には k 空間から画像空間への逆フーリエ変換**です。試験ではその方式全体を **フーリエ変換再構成** と呼びます。フーリエ変換の枠組みを使うのは、勾配で空間周波数としてサンプルしたデータを、位置表現の画像に戻すためです。
