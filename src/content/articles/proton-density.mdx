**MRI のプロトン密度（PD）とは**、その場所に**水素原子（プロトン）がどれだけ含まれているか**を表す考え方です。MRI は主に水の中の水素から信号を拾います。だからプロトン密度は、「**信号の材料がどれだけあるか**」をイメージするとわかりやすいです。

国試では「プロトン密度が高い組織は、T1 強調画像でも必ず一番明るい」といった**言い換えの罠**が出やすい。本記事では、例え話で意味を押さえつつ、そこを見抜くポイントまで整理します。

## 例え話：スタジアムの観客数

プロトン密度を、**スタジアムに入っている観客の人数**に例えてみましょう。

- **観客が多い** … 声を出せる人が多い（＝信号の材料が多い）
- **観客が少ない** … そもそも声が小さくなりやすい

ここまでは「人数＝プロトン密度」です。

でも実際の**音量（画像の明るさ）**は、人数だけでは決まりません。

- **大声で叫ぶ人が多いか、静かな人が多いか** … 組織ごとの性質（T1・T2）
- **マイクの設定や録音の仕方** … 撮り方（TR・TE などのシーケンス）

つまり、**「観客が最多＝必ず一番うるさい（明るい）」ではない**、というイメージです。

## MRI 画像の明るさは何で決まる？

画像の明るさ（信号強度）は、だいたい次の 3 つが関係します。

| イメージ               | MRI での意味                   |
| ---------------------- | ------------------------------ |
| 観客の人数             | **プロトン密度**（水素の多さ） |
| 人それぞれの声の出し方 | 組織の性質（**T1・T2**）       |
| 録音の設定             | **シーケンス**（TR・TE など）  |

**プロトン密度が高い** … 信号の**材料**は多い、という意味です。

**T1 強調画像・T2 強調画像** … 「どの性質を強調して見せるか」が違う撮り方です。それぞれ別の記事で詳しく扱う予定ですが、今回覚えるのは次の一点だけで十分です。

<KeyPoint>
  プロトン密度（水素の多さ）＋ 組織の性質（T1・T2）＋ 撮り方（シーケンス） →
  画像の明るさ
</KeyPoint>

## 国試で狙われる点：「最多＝最高信号」は誤り

次のような考え方は**誤り**です。

- **プロトン密度が最も高い組織は、T1 強調画像でも必ず最高信号になる**

正しくは、**T1 強調の明暗は TR・TE などで決まる**ので、プロトン密度だけ見て「必ず一番明るい」とは限りません。

### 代表例：脳脊髄液（CSF）

**CSF（脳脊髄液）** は、水が多い組織です。だから**プロトン密度は高い**部類に入ります。

それでも **T1 強調画像では暗く（低信号）** 見えやすい、というのが定番の例です。

|                   | CSF のイメージ         |
| ----------------- | ---------------------- |
| プロトン密度      | **高い**（水素が多い） |
| T1 強調での見え方 | **暗い**ことが多い     |

「水素が多い＝いつも白く（明るく）見える」ではない、と覚えておきましょう。

## よくある混同

- **CT の CT 値**（空気 0・水 1000 など）と混同しない … CT の濃度の話。MRI のプロトン密度とは別です。
- **「脂肪は水素が多いから常に明るい」** … シーケンス次第。T1 強調では明るく見えやすい脂肪もありますが、「プロトン密度だけで決まる」とは限りません。
- **PD 強調（プロトン密度強調）** … プロトン密度の差を出しやすい撮り方のひとつ。今回の「プロトン密度という概念」とは別です。「T1強調」、「T2強調」、「PD強調」のように、**画像の種類**として覚えると混乱が減ります。

## まとめ

**プロトン密度は、水素原子がどれだけあるか（信号の材料の量）** です。画像の明るさは、プロトン密度だけでなく **T1・T2 の性質**と**シーケンス**でも変わります。T1 強調で「プロトン密度が最も高い組織＝必ず最高信号」は誤りで、**CSF が典型の反例**です。
