- 「シンクロトロンとサイクロトロン、どっちがうず巻き？」
- 「炭素線治療で使う加速器はどれ？」
- 「ベータトロンって何を加速するの？」

この記事では、上記のような疑問にお答えします。

加速器は名前が似ていて、正直ややこしいです。<br />
全部まとめて覚えようと焦る必要はありません。

ひとつずつ見ていきます。

## シンクロトロンとは

まず、シンクロトロンがどう動くかを見ます。

陽子や炭素イオンは、プラスの電気を持った粒子です。<br />
電気を持った粒子は、磁場の中を通ると曲がります。<br />
磁石の力で曲げ続けると、粒子は円を描いて回ります。

ただし、粒子が速くなると、同じ磁場では曲がりきれません。<br />
円は大きくなろうとします。

そこで、粒子が速くなるのに合わせて、曲げる磁場を強くします。<br />
だから、粒子はいつも同じ大きさの円を回ります。<br />
軌道の半径は変わりません。

この、「**同じ円を回りながら、だんだん速くする装置**」を「**シンクロトロン**」と呼びます。

「シンクロ」は「同期（タイミングを合わせる）」という意味です。<br />
粒子の速さに合わせて、磁場の強さを上げます。<br />
エネルギーを足す電場（高周波）の周波数も、速さに合わせて上げます。

最初から止まった粒子を、リングで加速するわけではありません。<br />
まず、入射器（ライナックなど）で予備加速します。<br />
そのあと、リングに入れて加速します。

<KeyPoint>
  入射器（ライナック）で予備加速 → シンクロトロンで加速 → 取り出し → 治療室
</KeyPoint>

## リングの部品

次に、リングに並ぶ部品を見ます。<br />
役割を取り違えやすいところです。

| 部品 | 役割 |
| --- | --- |
| **偏向電磁石** | 粒子を曲げて、リングを回らせる |
| **四極電磁石** | ビームを細くまとめる（収束） |
| **高周波加速空洞** | 粒子にエネルギーを足す（加速） |

リングには、電磁石がたくさん並んでいます。<br />
しかし、電磁石は曲げたり、まとめたりするだけです。<br />
エネルギーは足しません。

エネルギーを足すのは、高周波加速空洞です。<br />
リング上の加速箇所は **1 か所**です。

例えば、陸上トラックを走る選手と、1 か所だけの給水所を思い浮かべてください。<br />
選手はトラックを何周もします。<br />
給水所を通るたびに、少しずつ元気（エネルギー）をもらいます。

だから、加速箇所が 1 か所でも、何周も回れば高いエネルギーになります。<br />
「電磁石の数だけ加速している」は**誤り**です。

## サイクロトロンとの違い

ここが、この記事の中心です。<br />
サイクロトロンと並べて見ます。

サイクロトロンは、磁場の強さが一定です。<br />
粒子が速くなると、円は大きくなります。<br />
だから、粒子はうず巻き状に外へ広がります。

サイクロトロンの中には、D 字形の電極（ディー）が 2 つあります。<br />
粒子は、ディーのすき間を通るたびに加速されます。

サイクロトロンは小型です。<br />
ただし、取り出すエネルギーは固定です。<br />
治療で深さを変えるには、エネルギーを下げる仕組み（デグレーダ）が要ります。

シンクロトロンは、軌道半径が一定です。<br />
磁場を強くしていきます。<br />
リングが必要なので、大型です。<br />
取り出すエネルギーは、変えられます。

| | サイクロトロン | シンクロトロン |
| --- | --- | --- |
| **軌道** | うず巻き（半径が大きくなる） | 同じ円（半径が一定） |
| **磁場** | 一定 | 速さに合わせて強くする |
| **大きさ** | 小型 | 大型 |
| **エネルギー可変** | 固定（デグレーダで下げる） | 変えられる |
| **主な用途** | 陽子線治療、PET 用核種の製造、PIXE 分析 | 炭素イオン線治療、陽子線治療 |

<KeyPoint>
  サイクロトロン ＝ 磁場一定・うず巻き
  <br />
  シンクロトロン ＝ 半径一定・磁場を強くする
</KeyPoint>

## どの治療で使うか

次に、どの加速器がどの治療に使われるかを見ます。<br />
国試で直接問われるところです。

- **重粒子線（炭素イオン線）治療（国内）** … シンクロトロン。HIMAC（量子科学技術研究開発機構）などの施設があります。
- **陽子線治療** … サイクロトロンも、シンクロトロンも使われます。
- **サイクロトロンの別の用途** … PET 用核種の製造（¹⁸F など）、PIXE 分析。

炭素イオンは、陽子よりずっと重いです。<br />
治療に要る深さまで届かせるには、大きなエネルギーが要ります。<br />
だから、国内の炭素線治療施設は、シンクロトロンで加速します。

「炭素線＝サイクロトロン」は**誤り**です。

## 加速できる粒子

加速器は、電場と磁場の力で粒子を押したり、曲げたりします。<br />
この力は、電気を持った粒子（荷電粒子）にしか働きません。

だから、加速器が加速できるのは、荷電粒子だけです。<br />
電子、陽子、炭素イオンは加速できます。<br />
電荷のない中性子は、加速できません。

中性子は、加速した陽子などを標的に当てて、核反応で二次的に作ります。

## ほかの加速器

最後に、ほかの加速器と、加速する粒子を見ます。<br />
引っかけの選択肢として、よく並びます。

| 加速器 | 加速する粒子・特徴 |
| --- | --- |
| **ライナック（直線加速器）** | 電子。X 線・電子線治療の主役 |
| **ベータトロン** | 電子。電磁誘導で加速する |
| **マイクロトロン** | 電子 |
| **タンデトロンなど静電型** | 高電圧で加速する。治療施設の主加速器ではない |
| **サイクロトロン** | 陽子など。陽子線治療、PET 用核種の製造 |
| **シンクロトロン** | 陽子・炭素イオン。粒子線治療 |

覚え方の軸は、「電子用か、重い粒子（陽子・炭素）用か」です。

ライナック、ベータトロン、マイクロトロンは、電子用です。<br />
サイクロトロン、シンクロトロンは、重い粒子用です。

## 国試で問われるポイント

引っかけになりやすい記述を並べます。

- 国内の炭素線治療は、サイクロトロンで加速する → **誤り**（正しくはシンクロトロン）
- シンクロトロンは、軌道半径が大きくなっていく → **誤り**（それはサイクロトロン。シンクロトロンは半径一定）
- サイクロトロンは、磁場を強くしていく → **誤り**（サイクロトロンは磁場一定。強くするのはシンクロトロン）
- シンクロトロンは、電磁石の数だけ加速する → **誤り**（加速は高周波加速空洞の 1 か所）
- サイクロトロンは、中性子を加速できる → **誤り**（加速できるのは荷電粒子だけ）
- マイクロトロンは、重イオン用の加速器である → **誤り**（電子用）
- ベータトロンは、陽子を加速する → **誤り**（電子を電磁誘導で加速する）

## まとめ

- シンクロトロンは、同じ円を回りながら、磁場を強くして加速します。
- 加速するのは、高周波加速空洞の 1 か所です。
- サイクロトロンは、磁場一定で、うず巻きです。
- 炭素線は、シンクロトロンです。
- 陽子線は、サイクロトロンとシンクロトロンの両方です。
- 電子用は、ライナック・ベータトロン・マイクロトロンです。
- 中性子は、加速できません。
