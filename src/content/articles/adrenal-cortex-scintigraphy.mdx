診療放射線技師国家試験で聞かれるのは下記です。

- 何の薬か
- 甲状腺ブロックは必要か
- デキサメタゾンって何？
- 副腎髄質用の薬と混同していないか

## 覚えるのはこれ

| 項目               | 国試で押さえる答え                                |
| ------------------ | ------------------------------------------------- |
| **代表的な薬**     | **¹³¹I-アドステロール**                           |
| **対象**           | 副腎**皮質**（髄質ではない）                      |
| **甲状腺ブロック** | **必要**（遊離ヨウ素対策）                        |
| **投与**           | **ゆっくり静注**（急速投与は避ける）              |
| **撮影**           | 投与直後ではなく**数日後**                        |
| **デキサメタゾン** | 正常な副腎皮質への集積を**抑制**                  |
| **混同しやすい薬** | **¹²³I-MIBG**（副腎髄質・褐色細胞腫の診断に使う） |

## 使用する放射性医薬品は何か

代表薬は **¹³¹I-アドステロール**（一般名はヨウ化メチルノルコレステノール（¹³¹I）注射液）です。

副腎皮質は、ステロイドホルモンを作ります。<br />
材料として**コレステロール**が必要です。<br />
そのコレステロールに似た形をした物質があります。<br />

<KeyPoint>それが、**アドステロール**です。</KeyPoint>

副腎皮質は、コレステロールに似たアドステロールも取り込みます。<br />
**¹³¹I-アドステロール**という、放射能をもった形にすれば、副腎皮質をガンマカメラでとらえられます。

<KeyPoint>
  ¹³¹I-アドステロール → 副腎皮質が材料として取り込む →
  ¹³¹I-アドステロールが放射線を出す → 副腎皮質が描出される
</KeyPoint>

以下の 2 点も覚えておきましょう。

- **遊離ヨウ素（¹³¹I）**が甲状腺へ行く可能性がある → 甲状腺ブロックが必要
- 半減期が約 8 日と長い → **数日後の撮影**と相性がよい

**¹²³I-MIBG** はノルアドレナリンに似た薬で、副腎**髄質**や交感神経をみます。<br />
副腎皮質用ではありません。<br />
ちなみに、¹²³I-MIBG も**甲状腺ブロックは必要**です。

## 甲状腺ブロックはなぜ必要か

結論から言うと、**甲状腺が無駄に被ばくしてしまう**からです。

先に普通のヨウ素（放射性ではないヨウ素）で席を埋めておきます。<br />
すると、あとから来た放射性ヨウ素は入れません。<br />
これが**甲状腺ブロック**です。

国試では、次の検査と並べて聞かれます。

| 検査                       | 代表的な薬          | 甲状腺ブロック                     |
| -------------------------- | ------------------- | ---------------------------------- |
| **副腎皮質シンチグラフィ** | ¹³¹I-アドステロール | **する**                           |
| **甲状腺シンチグラフィ**   | Na¹²³I など         | **しない**（甲状腺そのものを見る） |
| **副甲状腺シンチグラフィ** | ⁹⁹ᵐTc-MIBI など     | **しない**（テクネチウム製剤が主） |
| 肝胆道・唾液腺など         | ⁹⁹ᵐTc 系            | **しない**                         |

## 投与方法と撮影時期は？

### ゆっくり静注する理由

速く入れてしまうと、顔面紅潮や血圧の変動などの循環器症状が出やすくなります。

添付文書によると以下です。

- 生理食塩液または注射用水で **2 倍以上**に薄める。
- 30 秒以上かけて**ゆっくり静注する**。

薄める理由は、**エタノールが入っているため**です。

### なぜ投与後すぐに撮影しないのか

アドステロールは副腎皮質に入るまで時間がかかります。<br />
一方、投与後しばらくは肝臓などへも取り込まれます。

<KeyPoint>通常は**投与後 7 日目以降に撮影**とされています。</KeyPoint>

診療放射線技師国家試験では、「投与翌日に撮影する」という誤った選択肢が出てくるので注意です。

## デキサメタゾンは何のために使うか

デキサメタゾンは、合成の糖質コルチコイドです。<br />
体に「もう十分ステロイドがある」と伝える薬、と考えてください。

デキサメサゾンにより、下垂体からの「副腎皮質刺激ホルモン」が抑制されます。<br />
すると、正常な副腎皮質の働きが落ちます。<br />
これにより、¹³¹I-アドステロールの集まりも落ちます。

しかし、副腎皮質の病変部は、¹³¹I-アドステロールを取り込み続けます。

国試では、次の一文が正しい記述になります。

<KeyPoint>**デキサメタゾン投与で、正常副腎皮質への集積が抑制される**</KeyPoint>

## 対象疾患と集積の見方

| 疾患・所見                 | 国試での扱い                                                           |
| -------------------------- | ---------------------------------------------------------------------- |
| **原発性アルドステロン症** | 副腎皮質の病気。                                                       |
| **副腎皮質腺腫**           | 副腎皮質の腫瘤。                                                       |
| **正常な副腎皮質**         | 副腎皮質刺激ホルモンの支配を受ける。デキサメタゾンで集まりが落ちやすい |
| **褐色細胞腫**             | **副腎髄質**の病気。今回は無関係                                       |

## 副腎皮質と副腎髄質の違いは？

副腎は二層になっています。<br />
外側が皮質、内側が髄質です。<br />
作り出すホルモンも、使う薬も違います。

| 項目             | 副腎皮質                                                     | 副腎髄質                     |
| ---------------- | ------------------------------------------------------------ | ---------------------------- |
| **代表的な薬**   | **¹³¹I-アドステロール**                                      | **¹²³I-MIBG**                |
| **主な対象**     | 皮質の機能・病変の局在                                       | 髄質・交感神経系             |
| **関連する疾患** | 原発性アルドステロン症、皮質腺腫、クッシング症候群の一部など | **褐色細胞腫**、神経芽腫など |

## 国試直前の暗記まとめ

- **薬** … ¹³¹I-アドステロール（皮質）／¹²³I-MIBG（髄質）
- **ブロック** … ヨウ素標識 → 遊離ヨウ素 → 甲状腺被ばく防止
- **投与** … ゆっくり静注（30 秒以上）。急速は避ける
- **撮影** … 当日ではない。添付文書では 7 日目以降に撮影となっている。
- **デキサメタゾン** … 副腎皮質刺激ホルモンが落ちる。正常副腎皮質の集積も落ちる。
- **褐色細胞腫** … 副腎髄質の病気。

## 理解度を確認する問題

記事の内容だけで解けます。過去問とはちょっと変えてます。

### 問題 1

副腎皮質シンチグラフィで用いる代表的な放射性医薬品はどれか。

1. ¹²³I-MIBG
2. ⁹⁹ᵐTc-MIBI
3. ¹³¹I-アドステロール
4. ⁹⁹ᵐTc-PMT
5. ²⁰¹TlCl

**正解：3**

¹³¹I-アドステロールが副腎皮質用です。¹²³I-MIBG は髄質・交感神経系、⁹⁹ᵐTc-MIBI は心筋や副甲状腺、⁹⁹ᵐTc-PMT は肝胆道、²⁰¹TlCl は心筋などです。

### 問題 2

¹³¹I-アドステロールを用いる検査で、投与前にヨード剤による甲状腺ブロックを行う主な理由はどれか。

1. 副腎皮質への薬剤集積を増やすため
2. ACTH の分泌を抑えるため
3. 代謝などで遊離した放射性ヨウ素が甲状腺に集まるのを防ぐため
4. 甲状腺そのものを描出するため
5. デキサメタゾンの効果を高めるため

**正解：3**

ヨウ素標識薬から遊離した放射性ヨウ素が、甲状腺に取り込まれるのを防ぐ処置です。集積を増やす操作でも、ACTH を止める操作でもありません。甲状腺を見る検査では、逆にブロックしません。

### 問題 3

副腎皮質シンチグラフィでデキサメタゾンを使う目的として、適切なのはどれか。

1. 遊離ヨウ素の甲状腺集積を防ぐ
2. 正常な副腎皮質への集まりを抑え、自律性の病変との対比を見る
3. 褐色細胞腫への ¹²³I-MIBG 集積を増やす
4. 投与当日に撮影できるようにする
5. 急速静注でも副作用が出ないようにする

**正解：2**

デキサメタゾン → ACTH 抑制 → 正常皮質の集積抑制、が基本の流れです。甲状腺ブロックはヨード剤の役割です。撮影を当日にする効果も、急速投与を正当化する効果もありません。
