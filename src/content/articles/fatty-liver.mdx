**脂肪肝の超音波所見とは**、エコーで肝実質が腎皮質より明らかに明るく見える状態です。画面の上では白っぽく（高エコー）なり、同じ画面の右腎と比べると差がはっきりします。この比べ方を**超音波の肝腎コントラスト**と呼びます。肝が白く見える見た目は**ブライトリバー（bright liver）**とも言いますが、コントラスト（比べ方）そのものとは別の呼び名です。

国試では、右肋弓下の縦断で「肝が腎より白いか」「脈管壁が落ちて見えるか」がよく問われます。

## 例え話：細かい鏡がいっぱいになった部屋

超音波は、体の中に**音を飛ばして、跳ね返ってきた量**を明るさに変える検査です。跳ね返りが多いほど、画面は白くなります。

脂肪肝の肝臓を、**細かい鏡（油の粒）がたくさん浮いた部屋**に例えてみましょう。

- **普通の肝臓** … 部屋は少し曇ったガラス。音はほどほどに返り、画面は灰色
- **脂肪肝** … 油の粒が**小さな鏡**になって、音をたくさん跳ね返す。画面は**白く明るい**
- **右腎の皮質** … 隣の部屋。脂肪はあまり溜まらないので、明るさの**ものさし**になる

同じ窓から隣の部屋（右腎）と並べて見ると、「こっちの部屋だけ白い」がわかります。これが肝腎コントラストです。

<KeyPoint>
  脂肪肝の超音波 … 肝実質が腎皮質より高エコー（明るい）／比べる相手は右腎の皮質（肝腎コントラスト）
</KeyPoint>

## なぜ腎臓と比べるのか（肝腎コントラスト）

エコーの「明るさ」は、装置のつまみ（ゲイン）でも変わります。肝だけを見て「白い」と言っても、つまみを上げただけかもしれません。

そこで現場では、**脂肪が溜まりにくい右腎の皮質**を基準にします。

| 見え方                         | 読み方                         |
| ------------------------------ | ------------------------------ |
| 肝と腎皮質が**同じくらい**     | 肝の明るさはおおむね正常寄り   |
| 肝が腎皮質より**明らかに白い** | **脂肪肝**を強く疑う           |
| 肝が腎より**暗い**             | 別の話（急性肝炎など）。本問の典型ではない |

**ブライトリバー**は、「肝が白く明るい」という見た目の呼び名です。**超音波の肝腎コントラスト**は、腎と比べる評価の名前で、同じものではありません。国試では呼び名より、**腎皮質より高エコーかどうか**が本命です。

### 同じ画面に並べる理由

写真の明るさを比べるとき、別々の部屋で撮った2枚では照明が違います。エコーも同じで、肝だけの断面と腎だけの断面では条件がずれます。

**右肋弓下（みぎろっきゅうか）の縦断走査**は、肋骨のすぐ下から縦に当て、**肝と右腎を一つの画面に乗せる**定番の切り口です。ものさしと測りたいものを、同じ照明で並べるイメージです。

<KeyPoint>
  右肋弓下の縦断 … 肝と右腎を同じ画面に並べ、明るさを比べる（肝腎コントラスト）
</KeyPoint>

## 脈管壁が落ちて見える理由

正常の肝では、門脈などの**脈管壁**が細い白い線として見えます。チョークで灰色の黒板に線を引くと、線はよく目立ちます。

脂肪肝では黒板（肝実質）そのものが白くなります。**白い壁に白いチョーク**を引くようなもので、線が埋もれます。これを「脈管壁が相対的に落ちて見える」「脈管が不明瞭」と表現します。

肝全体が明るい、という所見の**補強**です。脈管だけを見て脂肪肝と決めるわけではありません。

## 似ているようで違う所見

右の上腹部エコーでは、脂肪肝以外の所見もよく出ます。場所が違うものを、肝の明るさと混ぜないのがコツです。

| 所見           | どこが変わるか           | 見え方のイメージ                         |
| -------------- | ------------------------ | ---------------------------------------- |
| **脂肪肝**     | **肝実質全体**           | 腎より白い。脈管壁が落ちて見えやすい     |
| **胆嚢結石**   | 胆嚢の**中**             | 点の強エコーと、後ろに落ちる暗い影       |
| **腹水**       | 肝と腎の**隙間**など     | 黒い無エコーのすき間（モリソン窩など）   |
| **水腎症**     | **腎盂**（腎の内側の袋） | 袋が無エコーに膨らむ                     |
| **脾腫**       | **左**の脾               | 右肋弓下の肝腎断面には出ない             |

結石の「後ろが暗い」は音が石で止まる影で、肝が白くなる話ではありません。腹水は**隙間が黒い**ので、肝実質が白い脂肪肝とは逆の場所を見ています。

## 国試でひっかかりやすい点

<KeyPoint>
  肝 ＞ 腎皮質（高エコー） ＋ 脈管壁が落ちて見える → 脂肪肝の超音波
</KeyPoint>

- **白い＝結石** … 結石は**点**と**後方の影**。肝**全体**が白いのは脂肪肝側です。
- **隙間が黒い＝脂肪肝** … 隙間の黒さは**腹水**。脂肪肝は実質が白い側です。
- **右の断面で脾を見る** … 脾は左季肋部。右肋弓下の肝腎像では判断しません。
- **腎が白い＝脂肪肝** … 比べる基準は**腎皮質**です。白いのは肝のほうです。
- **ゲインを上げただけ** … だから腎と**同じ画面**で比べます。

現場では脂肪の量を段階づける基準もありますが、国試ではまず **「腎より明るいか」** と **「他の所見と場所が違うか」** が取れれば十分です。

## まとめ

**脂肪肝の超音波所見**は、肝実質が右腎の皮質より明るく見えることです。右肋弓下の縦断で同じ画面に並べ、**超音波の肝腎コントラスト**を見ます。実質が白くなると脈管壁は相対的に落ちて見えます。結石・腹水・水腎・脾腫は場所が違うので、肝全体の明るさとは分けて覚えましょう。
