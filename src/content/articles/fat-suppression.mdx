**MRI の脂肪抑制（fat suppression）とは**、**脂肪組織の信号だけを暗く落とす**撮像法です。お腹まわりの MRI では、皮下の脂肪が画像を白く覆ってしまうことがあります。脂肪抑制をかけると、その「白い覆い」が薄くなり、肝臓・膵臓・血管・病変が見やすくなります。

国試では、**皮下脂肪が暗いかどうか**で脂肪抑制と水抑制（FLAIR）を見分ける問題や、**脂肪抑制 T1 の造影後像**を読む問題が出やすいです。

## 例え話：写真の「黄色だけ消す」フィルター

MRI 画像を、**色付きの写真**に例えてみましょう。

- **脂肪** … **黄色**の絵の具。皮下脂肪は、臓器の上にのった**厚い黄色のシート**のようなもの
- **水** … **青**の絵の具。脳室の CSF や、たくさんの水分を含むところにのりやすい
- **造影剤が入った血管** … **赤い蛍光ペン**でなぞった管のようなもの（T1 で明るく見える）

**脂肪抑制**は、「**黄色だけ色を薄くするフィルター**」です。黄色（脂肪）が消えるので、その下の臓器や、赤く光る血管（造影後）がはっきり見えます。

一方、**水抑制**（[FLAIR](/medical/articles/flair/)）は「**青だけ色を薄くするフィルター**」です。脳の MRI で、脳室の水（CSF）を暗くして病変を見やすくするときに使います。

<KeyPoint>
  脂肪抑制 … 脂肪を暗く（皮下脂肪が低信号） 水抑制（FLAIR） … 水を暗く（CSF
  が低信号） 「何が暗いか」で見分ける
</KeyPoint>

## 脂肪抑制と水抑制の見分け

| 撮像法              | 暗くなるもの           | 典型の所見         | よく使う場面      |
| ------------------- | ---------------------- | ------------------ | ----------------- |
| **脂肪抑制**        | **脂肪**               | **皮下脂肪が暗い** | 上腹部 T1、造影後 |
| **水抑制（FLAIR）** | **自由水（CSF など）** | **脳室・溝が暗い** | 頭部 T2 風画像    |

「抑制」という言葉は共通ですが、**落とす対象が違います**。国試では「皮下が暗いので水抑制」ような誤った選択肢が出やすいので、**暗くなっている部位**を先に確認しましょう。

## 脂肪抑制をかけた T1 強調ではどう見える？

| 部位・構造                   | 脂肪抑制なし T1 | 脂肪抑制あり T1 | 脂肪抑制 T1 **造影後** |
| ---------------------------- | --------------- | --------------- | ---------------------- |
| **皮下脂肪**                 | 明るい          | **暗い**        | **暗い**               |
| **大動脈・肝内脈管**         | やや暗〜中程度  | やや暗〜中程度  | **明るい（造影剤で）** |
| **囊胞など造影されない病変** | 暗い            | 暗い            | **暗いまま**           |

造影剤（Gd）のくわしい説明は [MRI 用ガドリニウム造影剤](/medical/articles/gadolinium/) の記事をどうぞ。次の節では、**なぜ造影後に脂肪抑制と組み合わせるのか**を整理します。

## なぜ造影後は脂肪抑制 T1 を撮るの？

「造影後なら、普通の T1 強調でも血管は明るく見える。わざわざ脂肪抑制をかける必要があるの？」——ここがよくある疑問です。

### 例え話：黄色いライトの部屋で赤い蛍光ペン

前の節で、脂肪を**黄色いライト**、造影剤の効果を**赤い蛍光ペン**に例えました。

- **脂肪抑制なし T1 造影後** … 部屋全体が**黄色く明るい**（脂肪）うえ、血管に**赤い線**（造影）を引いた状態。どちらも「明るい」ので、線が埋もれやすい
- **脂肪抑制 T1 造影後** … **黄色いライトだけ消す**。暗い背景に**赤い線だけ**がくっきり残る

T1 強調では、**脂肪も造影後の血管・病変も、どちらも明るく（高信号）** 見えやすい、というのがポイントです。脂肪抑制は「背景の脂肪の白さ」を消して、**本当に見たい増強部分**をはっきりさせるための加工です。

<KeyPoint>
  T1 … 脂肪も明るい ＋ 造影後 … 血管・病変も明るい
  → 脂肪抑制で脂肪だけ暗くし、増強部分を見分けやすくする
</KeyPoint>

### 3 つの理由（国試の範囲）

1. **脂肪は T1 でもともと明るい** … 皮下脂肪や大網脂肪は、造影前から白く見える
2. **造影後は「明るいもの」が増える** … Gd が入った血管や増強する病変も T1 で明るくなる
3. **脂肪抑制で背景を暗くする** … 脂肪の白さを消し、増強部分との**差（コントラスト）**を大きくする

### 上腹部で特によく使う理由

お腹まわりは**皮下脂肪・大網脂肪が厚い**部位です。脂肪抑制なしだと、臓器の縁や小さな増強病変が明るい脂肪に埋もれやすくなります。肝臓・膵臓・血管を評価する**上腹部の造影 MRI** では、**脂肪抑制 T1 造影後**が定番のプロトコール、と覚えておけば十分です。

頭部の造影 T1 では、必ずしも脂肪抑制をかけないこともあります（部位やプロトコールによる）。国試では、**皮下脂肪が暗い上腹部の画像**が出たら、脂肪抑制 T1 造影後を疑う、という読み方で問題ありません。

## 選択肢を消すときのコツ

問 6 の類似問題では、次の消去法も使えます。

| 選択肢の方向               | なぜ合わないか                                                           |
| -------------------------- | ------------------------------------------------------------------------ |
| **水抑制 T2**              | 脂肪は残りやすく、**皮下脂肪は明るい**方向。血管の造影効果も典型ではない |
| **脂肪抑制なし T1 造影前** | 皮下脂肪は**明るい**。血管もこれほど均一に明るくならない                 |
| **MRCP**                   | 強い T2 強調で**胆管・膵管**を見る検査。肝実質や大動脈の造影像ではない   |
| **拡散強調（DWI）**        | 設問の膵尾部は**低信号**。拡散制限なら**高信号**になりやすい             |

## 国試でひっかかりやすい点

- **皮下が暗い＝水抑制** … **誤り**。水抑制は**水**を落とす。皮下脂肪が暗いのは**脂肪抑制**。
- **脂肪抑制＝T2 だけ** … 上腹部では **T1 強調**（とくに造影後）とセットで出題されやすい。
- **血管が明るい＝T2** … T1 **造影後**でも血管は明るくなる。造影の有無を所見から推します。
- **「抑制」と聞くと FLAIR だけ思い浮かべる** … [FLAIR（水抑制）](/medical/articles/flair/) と **脂肪抑制**は別物。暗くなっている組織で区別する。

現場では STIR や SPIR など、装置ごとに呼び名が違う方式もありますが、国試では**画像所見（脂肪が暗いか）**を読めれば十分なことが多いです。

## まとめ

**脂肪抑制は脂肪組織の信号を暗く落とす撮像法**です。皮下脂肪が暗い所見なら脂肪抑制を疑い、**水抑制（FLAIR）とは混同しない**ようにします。造影後は脂肪も明るいので、**脂肪抑制 T1** で背景を暗くし、血管や増強病変を見分けやすくします。上腹部では脂肪が暗く・血管が明るく・造影されない病変は暗いまま、というパターンを覚えておきましょう。
