**PET 装置の性能評価**をやらないと、正しい診断ができません。<br />
性能評価には規格があり、**NEMA NU 2**と呼ばれます。<br />
診療放射線技師国家試験では 2018 年版の規格が問われます。

「評価項目」を覚えるだけだと不十分。<br />
国試では、その「**測定条件**」まで聞いてきます。<br />
覚えるのは、下の 2 つの表です。

## 評価項目

| 入る                    | 入らない                          |
| ----------------------- | --------------------------------- |
| 空間分解能              | **均一性**（ガンマカメラ／SPECT） |
| 感度                    |                                   |
| 散乱フラクション        |                                   |
| 計数率特性              |                                   |
| 画質                    |                                   |
| PET/CT の重ね合わせ精度 |                                   |

<KeyPoint>
  「空感・散計・画重（くうかん・さんけい・がじゅう）」と覚えましょう。
</KeyPoint>

<KeyPoint>
  「均一性」が、**誤った選択肢**で登場することがあります。「均一性」は、PET
  ではなく、「ガンマカメラ、SPECT」の評価項目。
</KeyPoint>

## 項目と測定条件

| 評価項目             | 測定条件                             | 説明                           |
| -------------------- | ------------------------------------ | ------------------------------ |
| **空間分解能**       | **点線源**（²²Na や ¹⁸F）            | 小さい点で、どれだけボケないか |
| **感度**             | 線源＋**アルミニウム管**（スリーブ） | 既知の厚さで、どれだけ拾えるか |
| **散乱フラクション** | **線源とファントム**                 | 体の中で散乱する割合           |
| **計数率特性**       | **散乱ファントム**                   | 忙しいときの数え落とし         |
| **画質**             | **NEMA IEC 胴体ファントム**          | 胴体に見立てて病変が見えるか   |

## まとめ

国試で覚えるのは、**項目の集合**と**項目↔条件の対応**だけです。分解能は点、散乱はファントム、感度はアルミ管、画質は IEC 胴体。均一性は PET のこの規格には入れません。
