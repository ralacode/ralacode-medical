**MRI 用ガドリニウム造影剤（Gd）とは**、**T1 強調画像**で血管や増強する病変を**明るく見せる**ための薬剤です。CT のヨード造影剤の MRI 版、とイメージしても構いません。

国試では、とくに **細胞外液に分布する Gd** の体内動態と安全性（MRCP・肝細胞取り込み・線状/環状・アレルギー頻度）が問われやすいです。本記事では、2026 年午前 問 5 で必要な範囲に絞って整理します。

## 例え話：血管の外側ににじむ食用色素

細胞外液性 Gd を、**血管の外に広がる食用色素**に例えてみましょう。

- **血管内** … 造影剤が最初に流れる場所。T1 で**明るく**見える
- **間質（細胞外液）** … 血管壁を越えて**にじみ出す**先。細胞の**中**には基本入らない
- **出口** … 腎臓でろ過され、**尿**として体外へ

「細胞外液に分布する」とは、**細胞と細胞のあいだ（間質）に広がる**という意味です。正常肝細胞の**中**へ選択的に取り込まれるタイプとは別物、と区別してください。

## 細胞外液性 Gd の体内動態

<KeyPoint>
  細胞外液性 Gd … 血管 → 間質へ広がる → 糸球体濾過 → 尿中排泄
</KeyPoint>

| ステップ | 内容 |
| --- | --- |
| 投与 | 静脈内（プレフィルドシリンジなど） |
| 分布 | **細胞外液**（血管・間質） |
| 排泄 | **糸球体濾過** → **尿** |

造影後の T1 強調で血管や増強病変が明るく見えるのは、この分布と T1 短縮効果によるものです。

## 他の Gd や検査との違い

| 項目 | 細胞外液性 Gd | 国試のポイント |
| --- | --- | --- |
| **MRCP** | **使わない** | T2 強調で胆汁・膵液を見る。Gd は不要 |
| **肝細胞特異性 Gd**（Gd-EOB-DTPA など） | 正常肝細胞へ**取り込まれる** | 細胞外液性には**その取り込みはない** |
| **非イオン性ヨード造影剤** | 別薬剤（CT 等） | Gd の重篤な即時型反応は、一般に**頻度が低い** |

## 線状型と環状型（マクロ環状型）

Gd イオンそのものは毒性があるため、**キレート**（有機分子で包む）して使います。その形で **線状型** と **環状型（マクロ環状型）** に大別されます。

| 型 | キレートのイメージ | 脳沈着（国試） |
| --- | --- | --- |
| **線状型** | 開いた鎖状 | 問題になりやすかった |
| **環状型** | 輪状に閉じた | **沈着しにくい**とされる |

「**環状型の方が脳へ沈着しやすい**」は**誤り**です。正しくは **線状型の方が沈着しやすい**、と覚えます。

## 2026 年 第 78 回 午前 問 5 のポイント

<a href="https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/topics/dl/tp260424-06a_01.pdf#page=6" target="_blank" rel="noopener noreferrer">第 78 回（2026 年）午前 問 5 の公式問題 PDF（6 ページ目）</a>は、**細胞外液に分布する Gd** の正誤を問う問題です。次をセットで押さえておきましょう。

- **正しい** … 主に**糸球体濾過**→**尿**排泄
- **誤り** … MRCP に必須 / 正常肝細胞へ選択的取り込み / 環状型の方が脳へ沈着しやすい / Gd のアナフィラキシーがヨード造影剤より多い

## 国試でひっかかりやすい点

- **MRCP に Gd が必要** … **不要**。T2 強調の検査です。
- **細胞外液性＝肝細胞に取り込まれる** … **Gd-EOB-DTPA など別タイプ**の話です。
- **環状型 > 線状型で脳沈着** … **逆**です。
- **Gd のアナフィラキシー > ヨード造影剤** … Gd の方が**低い**、が一般論です。

肝細胞特異性造影剤の詳しい記事は、別年次の問題が増えたタイミングで追加する予定です。

## まとめ

**細胞外液性ガドリニウム造影剤**は、間質に広がり**糸球体濾過で尿中へ**出ます。MRCP には使いません。肝細胞特異性製剤との混同に注意し、**線状型と環状型**では**環状型の方が脳沈着しにくい**、と覚えましょう。現場の **ガドビスト（環状）** と **マグネビスト（線状）** は、分類をイメージするための参考です。
