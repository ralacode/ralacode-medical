**無散瞳型の眼底カメラとは**、**散瞳せずに眼底（網膜・視神経など）を撮影する**装置です。糖尿病網膜症のスクリーニングなど、比較的短時間で多くの人を検査する場面でよく使われます。

国試では、**光の通り方（有孔ミラー）**と**操作の意味（固視灯・赤外観察・非接触）**が正誤問題として出やすいです。本記事では、問3（2026 午前）で必要な範囲に絞り、例え話で押さえます。

## 例え話：穴あきドーナツ型のライト

有孔ミラーの仕組みを、**真ん中に穴の空いたリングライト**に例えてみましょう。

- **リング状の光** … まわりから照らす（＝**照明光**）
- **真ん中の穴** … こちらから中を覗く・撮る（＝**観察・撮影光**）

同じ光が「照す側」と「見る側」に混ざると、まぶしさや反射で像が見えにくくなります。だから**照明と観察を分ける**のがポイントです。

## 有孔ミラー（照明と観察の分離）

<KeyPoint>
  照明光 … 有孔ミラーの**周辺**から眼底へ
  観察・撮影光 … 眼底から戻り、ミラー中央の**穴**を通ってカメラへ
</KeyPoint>

| 光の種類 | 向き | 通り道 |
| --- | --- | --- |
| **照明光** | 装置 → 眼底 | ミラーの**周辺**（穴の外側） |
| **観察・撮影光** | 眼底 → カメラ | ミラー**中央の穴** |

国試の定番は、「有孔ミラーは照明光と観察光（戻り光）を分ける」という理解です。

## 位置合わせは赤外光

撮影前に、瞳孔の位置や眼底像を合わせる**位置合わせ（アライメント）**があります。

- **赤外光**で観察する … 瞳孔を**縮めにくい**
- **紫外線**ではない … 位置合わせに UV を使う、という選択肢は誤り

目に見える強い可視光で長時間合わせると、瞳孔が縮んでしまい、無散瞳撮影がしづらくなります。だから**見えにくい赤外**で合わせる、と覚えておきましょう。

## 内部固視灯の役割

装置の中には、被検者に見せる**内部固視灯（ターゲット）**があります。

- **目的** … **どこを見てもらうか**（視線・撮影する眼底の部位）を決める
- **ピント合わせではない** … レンズの焦点調整は別の仕組み

「黄斑を撮る」「視神経乳頭を撮る」など、**視線の向き＝撮影部位**をそろえるための目印です。

## 非接触で撮影する

無散瞳型の眼底カメラは**非接触**です。

- 対物レンズを**角膜に押し当てない**
- 被検者の目の前に装置を置き、離れた状態で撮影

接触式の検査（例：眼圧測定でプローブを当てるなど）とは別物、と区別してください。

## 連続撮影について

**連続撮影は可能**です。ただし、撮影用の**フラッシュ光**で瞳孔が一時的に**縮瞳**するため、すぐ連写すると像が見えにくくなることがあります。

- 「連続撮影は**できない**」→ **誤り**
- 間隔を空ければ、**続けて撮影できる**

## 国試でひっかかりやすい点

| 誤りやすい表述 | 正しい理解 |
| --- | --- |
| 連続撮影はできない | **できる**（縮瞳するので間隔は空ける） |
| 位置合わせに紫外線 | **赤外光** |
| 固視灯はピント合わせ | **視線・撮影部位**の指定 |
| レンズを角膜に当てる | **非接触** |
| 有孔ミラーは光を混ぜる | **照明と観察を分ける** |

散瞳型との詳しい比較や視野角・光学系の種類などは、別年次の問題が増えたタイミングで本記事に追記していく想定です。

## まとめ

**無散瞳型の眼底カメラ**は、散瞳なしで眼底を撮る**非接触**の装置です。**有孔ミラー**で照明光と観察光を分け、位置合わせは**赤外**、**内部固視灯**で視線（撮影部位）を決めます。連続撮影も**可能**ですが、フラッシュで瞳孔が縮むので間隔に注意、が国試の要点です。
