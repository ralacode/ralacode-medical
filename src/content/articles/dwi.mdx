**MRI の拡散強調（DWI）とは**、組織の中で**水分子がどれだけ自由に動けるか**を強調して見る撮像法です。英語では Diffusion Weighted Imaging（**ディフュージョン**）と呼ばれます。

脳梗塞の**超急性期（発症から数時間）**では、細胞性浮腫で水分子の動きが制限され、**DWI でいち早く高信号**として描出されます。国試では、**DWI と T2 強調のどちらが先に変化するか**、**ADC マップとの関係**がよく問われます。

## 例え話：廊下で人が動けるかどうか

組織の中の水分子を、**廊下を歩く人**に例えてみましょう。

- **普通の組織** … 廊下が広く、人（水分子）が**自由に動ける**
- **拡散制限** … 細胞が腫れて廊下が**狭くなる**。人が動きにくくなる
- **DWI** … 「動きにくい場所」を**白く光らせて見せる**カメラ

脳梗塞の超急性期では、細胞性浮腫で細胞が膨らみ、水分子の拡散が落ちます。この「動きにくさ」を DWI が拾い、**病変が明るく**見えます。

<KeyPoint>
  拡散制限 … 水分子の動きが制限される DWI … 拡散制限があると高信号（明るい）
</KeyPoint>

## DWI と ADC マップ

DWI だけでなく、**ADC マップ**（見方のしやすさ係数マップ）もセットで出てくることが多いです。

| 画像           | 拡散制限があるとき   | イメージ                               |
| -------------- | -------------------- | -------------------------------------- |
| **DWI**        | **高信号（明るい）** | 「動きにくい場所」が光る               |
| **ADC マップ** | **低信号（暗い）**   | 「動きにくさ」の地図で、その場所が暗い |

本当の拡散制限では **DWI が明るい ＋ ADC が暗い**、とセットで覚えます。国試では「拡散強調は高信号、ADC は低下」が定番です。

T2 強調の明るさが DWI ににじんで見える **T2 shine-through**（T2 輝度効果）など、例外もありますが、問 8 の範囲では **超急性期脳梗塞＝DWI 高・ADC 低** で十分です。

## 超急性期脳梗塞：DWI と T2 の時間差

脳梗塞では、**DWI が T2 より先**に変化することがポイントです。

| 時期（目安）               | **DWI**    | **T2 強調**                          |
| -------------------------- | ---------- | ------------------------------------ |
| **超急性期（数時間）**     | **高信号** | **ほぼ等信号**（まだはっきりしない） |
| **亜急性期以降**           | 高信号     | **高信号**（遅れて明るくなる）       |
| **慢性期（嚢胞変性など）** | **低信号** | **高信号**                           |

T2 強調のくわしいコントラストは [FLAIR（水抑制）](/medical/articles/flair/) の記事で触れています。本記事では「**数時間では DWI が先、T2 は後**」と覚えれば問 8 は解けます。

<KeyPoint>
  発症数時間 … DWI 高信号 ＋ T2 ほぼ等信号 T2 だけ先に明るい …
  この時間帯の典型ではない
</KeyPoint>

は、発症から **1〜6 時間**の脳梗塞コアについて、**拡散強調像と T2
強調像**の組合せを問う問題です。

正しいパターンは次のとおりです。

- **拡散強調 … 高信号**（細胞性浮腫による拡散制限）
- **T2 強調 … 周囲とほぼ等信号**（まだはっきりしない）

## 選択肢を消すときのコツ

| 選択肢の方向           | なぜ合わないか                               |
| ---------------------- | -------------------------------------------- |
| **DWI 低・T2 高**      | 慢性期の嚢胞変性など。超急性期の典型ではない |
| **DWI も T2 も低信号** | 超急性期コアは DWI で**明るい**              |
| **DWI 等・T2 だけ高**  | T2 が先に目立つのは**亜急性以降**のイメージ  |
| **DWI 低・T2 等**      | 数時間で DWI が低信号になるのは典型ではない  |

## 国試でひっかかりやすい点

- **DWI が明るい＝T2 も必ず明るい** … **誤り**。超急性期は **DWI だけ先**。
- **拡散制限＝DWI 低信号** … **逆**です。拡散制限は **DWI 高信号**。
- **ADC を忘れる** … source 解説では **ADC 低下**もセット。DWI 高・ADC 低、とペアで覚える。
- **DWI と T2 強調を混同** … DWI は「拡散」、T2 は「T2 緩和」のコントラスト。別の撮像法です。

## まとめ

**拡散強調（DWI）は水分子の動きを見る撮像法**で、拡散制限があると**高信号**になります。**ADC マップ**では同じ部位が**低信号**です。超急性期の脳梗塞では **DWI が先に高信号**、**T2 強調はまだほぼ等信号**、という時間差を覚えておきましょう。
