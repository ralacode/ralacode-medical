- 「MRI の講義の内容がわからない、ついていけない」
- 「MRI の T1、T2 って何？」
- 「TR と TE って何？」

この記事では、上記のような疑問にお答えします。

学校で習う MRI の理論は正直難しいです。<br />
「やばい、理解できない」と焦る必要はありません。

## 「縦磁化」と「横磁化」

T1、T2 の前にこの 2 つの言葉を見てみましょう。

### 縦磁化とは

人間の体の中には、水素原子（プロトン）がたくさんあります。この水素原子（プロトン）は、普段はバラバラの方向を向いています。

水素原子（プロトン）は、MRI 装置のような強い磁石の力（静磁場）を受けると、磁場の方向を向きます。<br />
厳密に言えば、全部がピシッと同じ方向を向くわけではありません。<br />
まあ、細かいことは置いておいて。

この、「**磁場の方向へのそろい**」を「**縦磁化**」と呼びます。

### 横磁化とは

水素原子（プロトン）が磁場の方向を向いた状態で、MRI 装置から電波（RF パルス）を当てます。<br />
すると、そろっていた向きが横に倒れます。

この、横を向いた状態を「**横磁化**」と呼びます。

## T1 とは

横磁化が起きたあとに、電波（RF パルス）を当てるのをやめます。<br />
すると、水素原子（プロトン）は徐々に縦磁化に戻ります。

このときの、「**水素原子（プロトン）が縦磁化に戻るまでの時間**」を「**T1**」と呼びます。

例えば、「水」の水素原子（プロトン）と「脂肪」の水素原子（プロトン）の T1 は違います。

だから、**T1 強調画像では**、「水」と「脂肪」の見え方は違います。<br />
T1 強調画像では、「水」は暗く、「脂肪」は明るく見えます。

「水」の T1 は長く、「脂肪」の T1 は短いです。

## T2 とは

横を向いた水素原子（プロトン）は、くるくる回っています。<br />
最初は、みんな同じタイミングです。

タイミングは、だんだんずれます。
これを「**横磁化の減衰**」といいます。

この減衰の目安の時間を「T2」と呼びます。

例えば、「水」の水素原子（プロトン）と「筋肉」の水素原子（プロトン）の T2 は違います。<br />

だから、**T2 強調画像では**、「水」と「筋肉」の見え方は違います。<br />
T2 強調画像では、「水」は明るく、「筋肉」は暗く見えます。

「水」の T2 は長く、「筋肉」の T2 は短いです。

## TR と TE（縦磁化の回復と横磁化の減衰）

縦磁化に戻るまで、横磁化が減衰するまで。<br />
この待ち時間にも、名前があります。

- **繰り返し時間（TR）** … 次の電波（RF パルス）を当てるまでの時間です。このあいだに、水素原子（プロトン）は縦磁化に戻ります。
- **エコー時間（TE）** … 電波を当ててから、信号を聞くまでの時間です。このあいだに、横磁化は減衰します。

TR が短いと、T1 が長い「水」は、まだ縦磁化に戻りきっていません。<br />
信号は小さくなります。

T1 が短い「脂肪」は、短い TR でも縦磁化に戻っています。<br />
信号は残ります。

TR が長いと、水も脂肪も、だいたい縦磁化に戻っています。<br />
T1 の差は、あまり出ません。

TE が短いと、横磁化が減衰する前に信号を聞きます。<br />
T2 の差は、あまり出ません。

TE が長いと、T2 が短い「筋肉」は、横磁化がかなり小さくなっています。<br />
T2 が長い「水」は、まだ残っています。

<KeyPoint>
  短い TR … T1 が長いものは暗い（水）
  <br />
  長い TR … T1 の差は小さくなる
  <br />
  短い TE … T2 の差は小さい
  <br />
  長い TE … T2 が短いものは暗い（筋肉）
</KeyPoint>

TR を長くすると、待つ時間が伸びます。<br />
画像を作るには、この繰り返しが何回も要ります。<br />
だから、TR が長いと、撮像時間も長くなります。

同じ組織でも、静磁場が強いほど、T1 は長くなります。<br />
例えば「3 T（テスラ）の MRI 装置」では、「1.5 T（テスラ）の MRI 装置」より、**縦磁化に戻るのが遅い**です。

「短い TR」が何ミリ秒かは、装置で前後します。<br />
短い・長いの関係は、同じです。

## TR と TE の組み合わせ

スピンエコー法では、ずれたタイミングを、いったん揃えてから信号を取ります。<br />
次の表は、その目安です。

別の撮り方（勾配エコー）では、倒す角度でも明るさが変わります。<br />
ここでは、スピンエコーだけを見ます。

|             | **短い TE**          | **長い TE**                                          |
| ----------- | -------------------- | ---------------------------------------------------- |
| **短い TR** | **T1 強調**          | T1 と T2 が混ざる（T1 強調とも T2 強調とも呼ばない） |
| **長い TR** | **プロトン密度強調** | **T2 強調**                                          |

<KeyPoint>
  短い TR・短い TE … T1 強調
  <br />
  長い TR・短い TE … プロトン密度強調
  <br />
  長い TR・長い TE … T2 強調
</KeyPoint>

ミリ秒の目安です。装置や磁場で前後します。

- **短い TR** … 数百ミリ秒。戻りきる前に、次の電波を当てます。
- **長い TR** … およそ 2 秒より長い。多くの組織が戻ってから、次を当てます。
- **短い TE** … 20 ミリ秒前後より短い。
- **長い TE** … 80 ミリ秒前後より長い。

短い TR と、長い TE を組むと、どうなるでしょう。

縦磁化は、まだ戻りきっていません。<br />
横磁化も、かなり減衰してから聞くことになります。

信号は小さいです。<br />
T1 の差と T2 の差が、混ざります。

この組み合わせは、T1 強調でも、T2 強調でもありません。

## 組織の見え方

明るさは、「水が多いか」だけでは決まりません。<br />
T1 と T2、それに TR と TE の組み合わせで変わります。

| 組織               | T1 強調                    | T2 強調                                  |
| ------------------ | -------------------------- | ---------------------------------------- |
| **脳脊髄液（水）** | **暗い**                   | **明るい**                               |
| **脂肪**           | **明るい**                 | 水のように、いつも一番明るいわけではない |
| **白質と灰白質**   | 白質の方が明るく見えやすい | 灰白質の方が明るく見えやすい             |

### 水（脳脊髄液）

ここまで出てきた「水」は、脳の中では脳脊髄液です。

脳脊髄液は、T1 強調で暗く、T2 強調で明るく見えます。<br />
T1 が長く、T2 も長いからです。

水素が多いからといって、T1 強調で明るいとは限りません。<br />
脳脊髄液は水素が多いのに、T1 強調では暗く見えます。

詳しくは、[プロトン密度](/medical/articles/proton-density/)の記事で扱っています。

### 脂肪

脂肪の T1 は、短いです。<br />
短い TR でも、縦磁化に戻っています。

だから、**T1 強調画像では**、脂肪は明るく見えます。

T2 強調の明るさは、撮り方で変わります。<br />
水のように、いつも一番明るいわけではありません。

皮下脂肪を暗くしたいときは、[脂肪抑制](/medical/articles/fat-suppression/)をかけます。<br />
T1 強調で脂肪が明るいので、造影のあと、脂肪だけを消す、という使い方です。

### 白質と灰白質

白質には、神経を包む膜（ミエリン）が多いです。<br />
T1 は、灰白質より短めです。

だから、T1 強調では、白質の方が明るく見えやすいです。

灰白質は、水がやや多いです。<br />
T2 は、白質より長めです。

だから、T2 強調では、灰白質の方が明るく見えやすいです。

脳室の水が暗いかどうかと、白質・灰白質の明るさを、セットで見ます。<br />
あとで出てくる水抑制と、取り違えにくくなります。

### 出血の時期

出血の明るさは、血液の中身で変わります。<br />
新しいほうから、次の順で覚えることが多いです。

酸素化ヘモグロビン、デオキシヘモグロビン、細胞内メトヘモグロビン、細胞外メトヘモグロビン、ヘモジデリン。

何日目で次に進むかは、決まっていません。<br />
日数は、覚えなくて大丈夫です。

| 血液の中身                 | T1 強調        | T2 強調 |
| -------------------------- | -------------- | ------- |
| **酸素化ヘモグロビン**     | 周囲とほぼ同じ | 明るい  |
| **デオキシヘモグロビン**   | 周囲とほぼ同じ | 暗い    |
| **細胞内メトヘモグロビン** | 明るい         | 暗い    |
| **細胞外メトヘモグロビン** | 明るい         | 明るい  |
| **ヘモジデリン**           | 暗い           | 暗い    |

デオキシヘモグロビンは、T2 強調で暗く見えます。<br />
T1 強調では、まだ明るくなりません。

メトヘモグロビンになると、T1 強調で明るくなります。<br />
細胞の外に出ると、T2 強調でも明るくなります。

古くなってヘモジデリンが残ると、T2 強調で再び暗くなります。

これは、スピンエコーでの定番です。<br />
出血の大きさや、磁場の強さで、前後の段に見えることもあります。

## ほかの撮り方

### プロトン密度強調

プロトン密度強調は、長い TR・短い TE です。

T1 の差も、T2 の差も、小さくします。<br />
残るのは、水素の多さです。

脳脊髄液は、中くらいから明るく見えやすいです。<br />
T1 強調の「水は暗い」とは違います。

### FLAIR（水抑制）

FLAIR（水抑制）は、T2 強調に、もう 1 つ電波を足した撮り方です。<br />
この電波を、反転パルスといいます。

反転パルスは、縦磁化をいったん逆向きにします。<br />
脳脊髄液の縦磁化がゼロを横切るとき、信号を取ります。

だから、脳室や脳溝の水だけが暗くなります。

TR と TE は、長い側です。<br />
ただの T2 強調より、待ちがさらに長いことがあります。

脳脊髄液が暗いかどうかで、T2 強調と見分けます。<br />
詳しくは、[FLAIR（水抑制）](/medical/articles/flair/)を参照してください。

### 拡散強調

拡散強調の明るさは、TR と TE の長さだけでは決まりません。<br />
水の分子が、どれだけ動けるかを見て撮ります。

動きにくい場所が、明るくなりやすいです。<br />
T2 強調と名前が似ていても、明るさの理由は別です。

詳しくは、[拡散強調（DWI）](/medical/articles/dwi/)を参照してください。

画像のおおまかな明暗は、[k 空間](/medical/articles/k-space/)の中心に集まります。<br />
その明暗が T1 の差なのか、T2 の差なのかは、TR と TE で決まります。

## 国試でひっかかる点

- **短い TR・短い TE を、T2 強調と覚える** … T1 強調です。T2 強調は、長い TR・長い TE です。
- **長い TR・短い TE を、T2 強調と思う** … プロトン密度強調です。T2 強調は、TE も長くします。
- **脳脊髄液が暗いから、T1 強調** … T1 強調でも暗いです。FLAIR も、脳脊髄液は暗いです。白質と灰白質のどちらが明るいか、反転パルスがあるかも、一緒に見ます。
- **水素が多いから、T1 強調で明るい** … 脳脊髄液は、水素が多いのに暗いです。
- **TR を長くしても、撮像時間は変わらない** … 待つ時間が伸びるので、撮像時間も長くなります。
- **3 T でも、T1 の長さは弱い磁場と同じ** … 静磁場が強いほど、T1 は長くなります。
- **拡散強調の明るさを、TR と TE だけで決める** … 拡散強調は、水の動きにくさで明るさが決まります。

## まとめ

T1 強調は、短い TR・短い TE です。<br />
T2 強調は、長い TR・長い TE です。

水は、T1 強調で暗く、T2 強調で明るいです。<br />
脂肪は、T1 強調で明るいです。<br />
筋肉は、T2 強調で暗いです。

水素の多さや、拡散強調の明るさは、この組み合わせだけでは決まりません。
