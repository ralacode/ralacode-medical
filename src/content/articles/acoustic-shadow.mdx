**超音波の音響陰影とは**、石灰化や結石などの**強エコーのすぐ後ろが、縦に暗く落ちて見える**所見です。音がほとんど先へ進まないため、画面では真っ暗な帯になります。後方陰影、英語では acoustic shadow とも呼びます。

国試では、「暗い帯の名前は何か」「後ろが明るくなる所見と混同していないか」がよく問われます。

## 例え話：懐中電灯の前の厚いドア

超音波は、体の中に**音を飛ばして、跳ね返ってきた量**を明るさに変える検査です。跳ね返りが多いほど白く、来ないほど黒く見えます。

音を**懐中電灯**、石灰や石を**厚いドア**に例えてみましょう。

- **普通の組織** … ドアがなく、光（音）が奥まで届く。後ろも灰色に見える
- **音響陰影** … 厚いドアの**後ろは日陰**。縦に落ちる暗い帯になる
- **ドアそのもの** … 光を強く跳ね返すので、画面では**点や塊の強エコー**になる

だから音響陰影は、「白い点のすぐ深部に、暗い帯が伸びる」というセットで覚えます。

<KeyPoint>強エコー（石灰・結石）のすぐ深部に縦の暗い帯 → 音響陰影</KeyPoint>

## なぜ後ろが暗くなるのか

音は、空気や骨、石、粗い石灰のように**大きく性質の違う境目**で止まりやすかったり、跳ね返りやすかったりします。先へ進む量がごく少ないと、その奥からはエコーが返りません。

画面では、強エコーの**深部方向**（プローブから見て奥）が黒く抜けます。帯が縦に見えるのは、音の進む向きに沿って影ができるからです。

よく見る例は次です。

| 場所         | 強エコーの本体     | 後ろに落ちる影     |
| ------------ | ------------------ | ------------------ |
| 胆嚢         | 結石               | 音響陰影（典型）   |
| 甲状腺の結節 | 点状の石灰化など   | すぐ深部の暗い帯   |
| その他       | 骨、金属、ガスなど | 強い陰影が出やすい |

胆嚢結石の「点と影」は、[脂肪肝の超音波所見](/medical/articles/fatty-liver/)とは別物です。脂肪肝は肝**全体**が明るくなる話で、影の仕組みはこちら側です。

## 反対の所見：後方エコー増強

液体（嚢胞など）は、音が比較的**通りやすい通路**です。懐中電灯の前に、ドアではなく**ガラスの廊下**があるイメージです。光が奥まで届き、後ろの壁がかえって明るく見えます。

これを**後方エコー増強**と呼びます。音響陰影とは**明暗が逆**です。

| 所見               | 本体のイメージ       | 後ろの見え方 |
| ------------------ | -------------------- | ------------ |
| **音響陰影**       | 厚いドア（石・石灰） | **暗い帯**   |
| **後方エコー増強** | ガラスの廊下（液体） | **明るい**   |

<KeyPoint>
  音響陰影 … 後ろが暗い 後方エコー増強 … 後ろが明るい 暗い帯を増強と呼ばない
</KeyPoint>

## 似ているようで違う所見

甲状腺や腹部のエコーでは、影に似た言葉が並びます。**暗い／明るい**と**どこにあるか**で分けると迷いにくいです。

| 所見               | 見え方のイメージ                       | 音響陰影との違い             |
| ------------------ | -------------------------------------- | ---------------------------- |
| **音響陰影**       | 強エコーの後ろに、縦の**暗い帯**       | 深い日陰                     |
| **後方エコー増強** | 液体の後ろが**明るい**                 | 明暗が逆                     |
| **コメットエコー** | 短い**明るい尾**（膠質嚢胞など）       | 暗くない。深く落ちない       |
| **多重反射**       | 平行な面で音が往復し、**等間隔の偽像** | 一本の暗い帯ではない         |
| **ハロー**         | 結節を囲む**低エコーの縁**             | 深部へ伸びる帯ではない       |
| **側方陰影**       | 丸い境界面の**端**から細く落ちる影     | 中央の強い陰影とは位置が違う |

コメットエコー（リングダウンに近い短い尾）は、きらきらした火花が少し後ろに残る感じです。音響陰影の「長い日陰」とは印象が違います。

## 国試でひっかかりやすい点

- **暗い帯** ── **後方エコー増強** … この組み合わせは**誤り**。増強は後ろが**明るい**。暗い帯は音響陰影側です。
- **短い明るい尾** ── **音響陰影** … この組み合わせは**誤り**。短い明るい尾はコメットエコー寄りです。
- **結節の縁が暗い** ── **音響陰影** … この組み合わせは**誤り**。縁取りはハローで、深部へ落ちる帯ではありません。
- **等間隔の線** ── **音響陰影** … この組み合わせは**誤り**。等間隔の偽像は多重反射です。

現場では陰影の強さで石灰の性状を読むこともありますが、国試ではまず **「後ろが暗いか明るいか」** と **「帯か縁か尾か」** が取れれば十分です。

## まとめ

**超音波の音響陰影**は、強エコーのすぐ後ろが縦に暗く落ちる所見です。音が石や石灰で止まるために日陰ができます。液体の後ろが明るくなるのは**後方エコー増強**で、明暗が逆です。コメットエコー・多重反射・ハローは場所も形も違うので、暗い帯と混ぜないようにしましょう。
